Cyber Security Internship - Task 2: Phishing Email Analysis

Objective
The goal of this task is to analyze a suspicious email sample, identify various phishing indicators (like spoofed headers, urgent language, and malicious links), and understand the basics of email-based threats.

Steps Performed
1. Selected a realistic phishing email sample mimicking a security alert.
2. Analyzed the sender's address and email body for common phishing signs (generic greetings, grammatical errors).
3. Inspected the URL behavior (mismatched links).
4. Created a detailed report highlighting the phishing indicators found.
5. Answered the task interview questions.

Outcome
Developed practical skills in identifying email threats, understanding attacker psychology (social engineering), and analyzing malicious indicators.
